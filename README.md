# Reinforced Learning — CNN & RL Curriculum

Notebooks supporting a tiered CNN/reinforcement-learning curriculum for MBO/HBO/WO students, published as interactive lessons at [projectenplaats.nl/lessons](https://projectenplaats.nl/lessons).

## Notebooks

- **`cnn_warmup_demo.ipynb`** — a from-scratch introduction to CNNs: pixel grids, hand-crafted convolution filters, then a real PyTorch model trained on scikit-learn's digit dataset. For students who already know Python.

Open any notebook directly in Google Colab via the "Open in Colab" badge on GitHub, or via `https://colab.research.google.com/github/davorradic/reinforced-learning/blob/main/<notebook>.ipynb`.
